# Dr. Maya Reynolds – Therapy Website

A responsive homepage clone and creative redesign built for the **Grow My Therapy** assignment. The layout is based on [Conejo Valley Counseling](https://www.conejovalleycounseling.com/home), re-themed with new copy, colors, and images for an imaginary therapist, Dr. Maya Reynolds.

## Tech Stack

- Next.js
- Tailwind CSS
- Deployed on Vercel

## What's Inside

- **Homepage Clone:** Matches the original layout, spacing, typography, and section order, fully responsive across desktop, tablet, and mobile.
- **New Theme:** Custom primary, secondary, and accent palette, managed through Tailwind config / CSS variables for easy maintenance.
- **Original Copy:** All headlines, services, About, and FAQs written from Dr. Reynolds' profile and SEO-optimized for her local region.
- **New Images:** Replaced with theme-matched visuals, plus Maya's photo and bio.
- **"Our Office" Section:** A new custom section showcasing her practice space, using office photos from her profile.
